# Archived prototypes

The files in this folder are early, standalone design prototypes for what became
the current `app/` — they predate this fork's branding and legal-disclaimer
fixes (see `CHANGELOG.md` at the repo root) and are **not** part of the live
site, not imported by anything under `app/`, and not deployed anywhere.

Some of these prototypes still carry an early "Birmingham City Council" concept
label and the council crest, from before this project became independent. If
you're looking for the current, correct branding and disclaimers, see the live
app (`app/`) instead — these files are kept only for design history.
